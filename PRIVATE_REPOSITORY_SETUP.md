# Private GitHub Repository Setup

Recommended repository name:

source-aware-stabilized-soil-ml

Visibility:

Private

Description:

Dataset and analysis code for source-aware machine learning of stabilized expansive soils.

How to use:

1. Create a new GitHub repository with the name above.
2. Set visibility to Private.
3. Do not initialize with README, license, or .gitignore because these files already exist here.
4. Copy the private repository URL.
5. Open `PUSH_PRIVATE_REPO.ps1`, replace `<YOUR_GITHUB_USERNAME>` with your GitHub username, then run it from this folder.
6. When reviewers ask, either make the repository temporarily public, invite reviewer/editor GitHub accounts, or create a private release/shareable archive depending on journal policy.

Note:
The repository should remain private until the journal/editor asks for access or until you decide to make the dataset public.
